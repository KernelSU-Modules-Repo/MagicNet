###项目简介
主要功能是以**TUN模式**在安卓设备运行**mihomo**，预配置集成社区共建黑名单。
欢迎贡献代码或提交规则！（仅mihomo内核）

亮点：
开箱即用
支持singbox/mihomo
真*透明代理，开热点化身魔法热点
并且支持和其他vpn软件共存
低内存占用
开机自启动

>⚠️**注意**：本模块需要**Root权限**(KernelSU/APatch/Magisk)
