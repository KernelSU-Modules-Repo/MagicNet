## 项目简介
>>>>>>> 8850eca (module.json)

MagicNet 是一个面向 Android Root 设备的透明代理模块，主要通过 TUN 模式运行 mihomo，并内置社区共建规则，尽量减少手动配置成本。

模块适用于 KernelSU、APatch、Magisk 等 Root 环境。安装后可在设备侧接管网络流量，并按规则处理代理、直连与黑名单路由。

> 注意：本模块需要 Root 权限。
